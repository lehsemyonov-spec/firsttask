# Шпаргалка для записи: что вставлять на каждом шаге

Держи этот файл открытым рядом (второй экран, телефон или окно сбоку). Агенту его **не показывай**.
Порядок всегда один: **дождись, что агент закончил → вставь текст → сделай действие → жди результат**.
Подробный сценарий и план монтажа — `docs/video-run.md`.

---

## 0. Запуск (до первого сообщения)

1. Включи запись экрана.
2. Открой терминал и перейди в папку проекта:

```
cd путь/к/firsttask
```

3. Запусти Claude Code:

```
claude
```

4. **Жди:** при старте появится подсказка хука «Проекты „Стратега продуктов“… vozvratim: шаг 6 (готов)». Задержи кадр на 2–3 секунды.
5. Голосом (≈20 с): «Это агент „Стратег продуктов“ — папка с правилами и проверками для Claude Code. Даю ему бриф МегаФона и прохожу путь до стратегии».

---

## Шаг 1. Постановка задачи → 🛑 согласовать бриф

**Вставь:**

```
Новый проект: связь для близких и собственных устройств. Бриф МегаФона лежит в projects/svyaz-blizkih/materials/brief-megafon.pdf — по нему нужно сделать стратегию. Других материалов нет, данные в брифе учебные.
```

**Жди:** агент создаст проект, прочитает бриф и покажет: черновик брифа, **формат результата — 5 частей**, до 3 вопросов, фразу вида «подтвердите бриф». Он должен **остановиться**.

**Сделай:** проверь, что в формате пять частей брифа. Если нет — напиши, каких не хватает.

**Вставь (согласование):**

```
Согласовано. Получатель — руководитель направления и финансовая команда, документ из пяти частей по структуре брифа. Открытые сведения о реальных операторах можно как фон, числа — только из брифа. Срока нет, первую группу клиентов выбери сам по итогам исследования. Продолжай.
```

---

## Шаги 2–3. Сбор материалов и исследование (вставлять ничего не нужно)

**Жди:** агент сам пройдёт шаги 2 и 3 без остановок: источники, факты со ссылками на страницы брифа, расчёты скриптами, пробелы, картина ситуации. В конце — короткая сводка шага 3 и переход к вариантам (или остановка перед ними).

**Сделай (для кадра):** когда появится сводка шага 3 — открой файл `projects/svyaz-blizkih/situation.md` на 5–10 секунд. Голосом: «Агент раскладывает цифры брифа по фактам со ссылкой на страницу и считает скриптами, а чего нет — записывает пробелом».

**Если агент остановился и ждёт** (например, спросил «продолжать?»):

```
Продолжай.
```

---

## Шаг 4. Варианты → 🛑 выбрать вариант

**Жди:** 4–5 вариантов; среди них «оставить как есть» и «свернуть»; у каждого — возражения (помощник `skeptic`); рекомендация; просьба выбрать. Агент **останавливается**.

**Сделай:** найди номер варианта про предупреждение организатору семейной группы (что у близкого кончается интернет). Подставь его вместо `O…`.

**Вставь:**

```
Выбираю O… в минимальном виде — без нового кабинета, с условиями первого квартала, как ты предложил. Почему: он бьёт и в долю активных групп, и в уход, а передача интернета уже существует, значит, разработка укладывается в выделенные 3 человеко-месяца. Владельцев роутеров — второй очередью, понятные списания — запасной путь. Параллельную проверку привлечения и активации групп тоже включи в план.
```

Если агент рекомендовал другой вариант — выбери его рекомендацию и напиши «почему» своими словами, одной фразой.

---

## Шаг 5. Стратегии → 🛑 утвердить

**Жди:** продуктовая и коммуникационная стратегии коротко, таблица «Проверка обещаний», просьба утвердить. Агент **останавливается**.

**Сделай (для кадра):** покажи таблицу «Проверка обещаний» (в ответе агента или в `projects/svyaz-blizkih/comms-strategy.md`).

**Вставь:**

```
Утверждаю обе стратегии. Пороги плана проверки предложи на шаге 6. Переходи к шагу 6 и собери итоговый документ.
```

---

## Шаг 6. План проверки и итог

**Жди:** пороги для решений Q1 и Q2, резюме, документ из пяти частей, отчёт; агент спросит подтверждения порогов.

**Вставь:**

```
Пороги подтверждаю.
```

### 6а. ⏸ Перерыв (обязательная часть видео)

**Жди**, пока агент ответит на подтверждение порогов. **Вставь:**

```
Стоп.
```

**Жди:** «состояние сохранено, продолжить — …». **Сделай:** выйди из Claude Code:

```
/exit
```

Голосом: «Новый чат: агент не помнит переписку, он восстанавливается по файлам проекта». Снова запусти:

```
claude
```

**Жди** подсказку хука при старте (теперь в списке есть и `svyaz-blizkih`). **Вставь:**

```
Продолжи проект svyaz-blizkih
```

**Жди:** агент сам скажет, где остановились (все шаги пройдены, пороги подтверждены), ничего не переделывая.

### 6б. Новые данные (обязательная часть видео)

Голосом: «Даю учебные новые данные — как и весь бриф, они вымышлены». **Вставь:**

```
Новые данные: владелец системы расчётов сообщил, что остаток интернета у участника обновляется в приложении с задержкой от 30 минут до 3 часов, в среднем около 1,5 часа. Совместимых тарифов — 40 % групп.
```

**Жди:** новый источник, пометки «устарел» у затронутых прогнозов, пересчёт, таблица «держится / ослабло», агент заметит, что обещание «предупредим в момент низкого остатка» стало неточным, и **спросит согласия** на правки. **Вставь:**

```
Согласен с правками. Внеси их и пересобери отчёт.
```

### 6в. Финал

**Вставь:**

```
Что решать сейчас?
```

**Жди** ответ. **Вставь:**

```
Собери отчёт
```

**Сделай (для кадра):** открой `projects/svyaz-blizkih/report.md`: резюме на первой странице → «Документ по структуре заказчика» (пять частей) → приложения. Покажи затраты (раздел «Затраты» в конце отчёта или `cost.md`).

Голосом (≈15 с): что получилось, сколько стоило, сколько минут заняло у тебя.

Выключи запись.

---

## После записи (вне кадра)

```
/export
```

Сохрани переписку. Затем в терминале — по одной команде:

```
git add projects/svyaz-blizkih
```

```
git commit -m "Демо-проект по брифу МегаФона"
```

```
git push
```

Пришли в чат с Claude: файл экспорта, «запушил», расход и время, видео (или кадры) — для монтажа.

---

## Если что-то не так

| Что | Что делать |
|---|---|
| Агент пошёл дальше без твоего ответа на 🛑 | `Стоп.` → дай ответ из шпаргалки. В монтаже вырежешь |
| Спросил больше трёх вопросов / другое | Ответь по смыслу текста согласования |
| Сайт не открылся | Нормально, агент запишет это сам |
| `check` показал ошибку | Не помогай — агент исправит сам (хороший кадр) |
| Совсем сломалось | Останови запись, напиши в чат с Claude |
