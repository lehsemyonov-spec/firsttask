# Паспорт данных и воспроизводимый расчёт

1. Для каждой таблицы: `python tools/data_check.py projects/<slug>/materials/<файл> --out projects/<slug>/analysis/<файл>.md` (для XLSX с несколькими листами — `--sheet`).
2. Разбери предупреждения. Неясные единицы или период — спроси человека (с вариантом по умолчанию), запиши допущение в `facts.md`.
3. Любой расчёт (динамика, доли, когорты, сравнение периодов) — отдельным скриптом `projects/<slug>/analysis/<название>.py`. Скрипт читает исходный файл и печатает результат, чтобы его можно было перезапустить.
4. В `facts.md`: тип `факт` для прямых значений из таблицы, `вывод` для расчётов; основание — `S… + analysis/<скрипт>.py`.
5. В комментарии к источнику в `sources.md` отметь период, единицы и найденные проблемы.
