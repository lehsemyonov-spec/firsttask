# Пересмотр при новых данных

1. Занеси новый материал: источник в `sources.md`, утверждения в `facts.md` (новые ID). **Старые строки не удаляй и не переписывай** — меняй их статус:
   - `устарел` — было верно, но есть более свежие данные (новая цифра за следующий период);
   - `отозван` — оказалось неверным (ошибка в источнике, опечатка, источник не про то).
   Команда ставит статус, причину и запись в журнал сразу:
   `python tools/strategist.py impact <slug> F2 --status отозван --mark "<причина>, верно — F9"`
2. Для каждого изменённого `S…`/`F…` выполни (если не сделал в п. 1):
   `python tools/strategist.py impact <slug> <ID> --mark "<что изменилось>"`
   — получишь цепочку зависимых утверждений, разделы вариантов и стратегий и решения из `decisions.md`.
   Затем `check`: ссылки на отозванное в вариантах, стратегиях, картине ситуации и резюме — ошибки, на устаревшее — предупреждения; выводы, которые держатся на отозванном, тоже подсвечиваются.
3. Для каждого затронутого места реши: вывод **держится** / **ослаб** / **опровергнут**. Покажи человеку короткую таблицу и предложи правки. Существенная смена рекомендации — точка выбора человека.
4. После согласования внеси правки: замени ссылки на отозванные факты действующими или убери выводы, которые без них не держатся. У затронутых решений в `decisions.md` поменяй статус (`пересмотреть` / `отменено` / `подтверждено <дата>`). Решение со статусом «действует» на отозванном факте `check` не пропустит.
5. Очисти обработанные строки в `state.md › Помечено к пересмотру`, запиши итог в `log.md`, прогони `check`.
