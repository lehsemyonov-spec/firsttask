# Модельные интервью

Методика: `knowledge/interviews.md`. Результаты: `projects/<slug>/interviews.md`.

1. Составь гайд (8–12 вопросов о прошлом поведении) под вопросы `research-plan.md`.
2. Опиши 3–5 разных персон (обязательно скептик и не-пользователь), опираясь на факты `F…`, где они есть.
3. Для каждой персоны вызови субагента `respondent`, передав только описание персоны и вопросы — без гипотез команды. Персоны можно опрашивать параллельно.
4. Запиши в `interviews.md` главное по каждой беседе и общий список гипотез «проверить на людях».
5. В `facts.md` заводи только тип `синтетика` с основанием «модельное интервью, P…».
6. Сообщи человеку: что нашлось, что это не доказательство, и как проверить главные гипотезы на реальных людях (гайд готов).
7. Запиши стоимость: `cost add --step 3 --what "модельные интервью, N персон" --model haiku …`.
