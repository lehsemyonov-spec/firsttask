# Промпт для обычного чата (участник B)

## Первое сообщение

Приложить бриф (`brief-megafon.pdf` или вставить текст `brief-megafon.md`) и отправить без изменений:

> Ты — продуктовый стратег. Вот бриф руководителя цифрового продукта. Подготовь стратегию по этому брифу: картину ситуации (что известно и откуда, чего не знаем), не меньше трёх вариантов, включая «оставить как есть», с возражениями, рекомендацию, продуктовую и коммуникационную стратегии и план проверки. Указывай источники. Если тебе не хватает сведений — спроси.

Промпт специально обычный, такой написал бы руководитель без подготовки. Подробности не добавлять: сравнивается именно способ работы.

## Ответы руководителя (те же сведения, что получает агент)

Давать **только если чат спросил** — по смыслу вопроса, теми же словами:

| О чём спросили | Ответ |
|---|---|
| Получатель, формат, срок | Получатель — руководитель направления и финансовая команда, документ из пяти частей по структуре брифа. Срока нет |
| Можно ли данные о реальных операторах | Да, как фон; числа — только из брифа |
| Какую группу клиентов выбрать | Выбери сам по итогам анализа |
| Выбор варианта (если чат предложил варианты и ждёт решения) | Выбираю вариант про предупреждение организатору семейной группы, что у близкого кончается интернет, в минимальном виде, с условиями первого квартала. Владельцев роутеров — второй очередью, понятные списания — запасной путь. Параллельную проверку привлечения и активации групп тоже включи в план |
| Утвердить стратегию / пороги | Утверждаю. Пороги плана проверки предложи сам |

Если чат выбрал другой вариант без вопроса — не поправлять, записать.
