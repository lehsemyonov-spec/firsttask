# Краткая инструкция: что за что отвечает

## Как пользоваться (3 шага)

1. Откройте папку в Cursor, Claude Code, Codex или другой ИИ-среде.
2. Напишите агенту: «Новый проект: <ваша задача>». Материалы положите в `projects/<проект>/materials/`.
3. Отвечайте агенту в трёх точках выбора 🛑: согласовать бриф, выбрать вариант, утвердить стратегию.

Продолжить после перерыва, в том числе в новом чате: «Продолжи проект <название>».

## Карта репозитория

| Файл / папка | За что отвечает | Кто меняет |
|---|---|---|
| `AGENTS.md` | **Главный «мозг»**: роль агента, жёсткие правила, порядок шагов, команды, поведение при сбоях | только человек |
| `CLAUDE.md`, `GEMINI.md`, `.cursor/rules/`, `.github/copilot-instructions.md` | Переходники: заставляют разные среды прочитать `AGENTS.md` | никто |
| `workflow/01…06-*.md` | Инструкция для каждого шага: что сделать, когда остановиться и спросить, когда шаг считается готовым | только человек |
| `knowledge/` | Методики: как отличать факт от гипотезы, исследовать, проводить интервью, строить варианты, писать стратегии и план проверки, правила безопасности | только человек |
| `templates/` | Заготовки файлов, из которых создаётся каждый новый проект | только человек |
| `projects/<проект>/` | Всё по конкретной задаче: материалы, рабочие файлы, состояние | агент |
| `tools/strategist.py` | Главный скрипт: создать проект, показать статус, проверить шаг, вести журнал и затраты, собрать отчёт, найти зависимости (`impact`), посчитать метрики | никто |
| `tools/extract_text.py` | Текст из DOCX, PPTX и PDF в markdown с номерами страниц и слайдов; помечает фразы, похожие на команды агенту | никто |
| `tools/data_check.py` | Проверка таблиц CSV/XLSX: пропуски, единицы, периоды, выбросы | никто |
| `tools/hook.py` | Автопроверки в Claude Code: в начале сессии и после каждой правки | никто |
| `.claude/agents/` | Помощники: `skeptic` (возражения), `fact-checker` (сверка с источниками), `respondent` (модельный собеседник) | только человек |
| `.claude/skills/` | Готовые процедуры: пересмотр при новых данных, модельные интервью, паспорт данных | только человек |
| `.claude/settings.json` | Подключение хуков для Claude Code | только человек |
| `benchmark/` | Как сравнить агента с обычным чатом и аналитиком, шаблон результатов | человек |
| `docs/architecture.md` | Черновик описания работы для PDF | человек |
| `docs/task.md` | Полный текст условий конкурса (сверять формулировки требований) | человек |
| `tests/` | Автотесты скриптов на учебном проекте с вымышленными данными | никто |
| `README.md` | Полная инструкция запуска и ключевые решения | человек |

## Файлы внутри проекта (`projects/<проект>/`)

| Файл | Что в нём | Шаг |
|---|---|---|
| `state.md` | **Где остановились** и что делать дальше. Отсюда агент продолжает работу | все |
| `log.md` | Журнал: что агент сделал, ошибки инструментов, правки человека | все |
| `cost.md` | Сколько стоил каждый шаг: токены, $, минуты человека | все |
| `materials/` | Исходные материалы человека. Агент их только читает | 1–2 |
| `brief.md` | Постановка задачи: вопрос, решение, цель, получатель, ограничения | 1 |
| `sources.md` | Реестр источников `S1, S2…` со ссылками и надёжностью | 2 |
| `research-plan.md` | Вопросы, ответ на которые может изменить решение | 3 |
| `facts.md` | Реестр утверждений `F1, F2…` с типом: факт / вывод / гипотеза / прогноз / синтетика | 3 |
| `unknowns.md` | Чего не знаем, почему и как это повлияет на решение | 3 |
| `interviews.md` | Гайд, персоны, итоги интервью (модельные — только как гипотезы) | 3 |
| `analysis/` | Паспорта таблиц и скрипты расчётов | 3 |
| `options.md` | Варианты, возражения, сравнение, рекомендация, выбор человека | 4 |
| `product-strategy.md` | Продуктовая стратегия | 5 |
| `comms-strategy.md` | Коммуникационная стратегия и таблица «обещание → чем подтверждено в продукте» | 5 |
| `validation-plan.md` | План проверки: что ждём, с чем сравниваем, сколько ждём, чего опасаемся | 6 |
| `decisions.md` | Журнал решений: основания, ответственный, условие пересмотра | 6 |
| `report.md` | Итоговый документ для руководителя (собирается командой) | 6 |

## Что можно сказать агенту

«Статус» · «Стоп» · «Продолжи проект …» · «Вернись к шагу N» · «Исправь …» · «Новые данные: …» · «Что решать сейчас?» · «Собери отчёт»

## Что работает автоматически

- **Проверка при переходе шага:** агент не идёт дальше, пока `strategist.py check` находит ошибки (нет источника, меньше трёх вариантов, нет выбора человека…).
- **Только в Claude Code:** хук в начале сессии показывает, где остановились; хук после правки ловит битые ссылки, синтетику в роли доказательства, ключи и персональные данные. Помощники вызываются как субагенты.
- **В других средах** те же проверки и роли агент выполняет по инструкциям, без автоматического запуска.
