# Что лежит в materials/

Опись для агента: откуда каждый файл. Выводов здесь нет — только происхождение.

| Файл | Что это | Откуда, когда |
|---|---|---|
| `idea-owner.md` | Исходная идея сервиса словами владельца | Владелец проекта, 18.11.2026 |
| `product-brief.md` | Продуктовая записка: оценка идеи, роли, этапы, носители, монетизация, риски | Написана ИИ-агентом в Cursor по просьбе владельца при разработке прототипа; источников внутри нет |
| `homepage-structure.md` | Структура главной страницы и визуальный тон | Там же, при разработке прототипа |
| `images/*.png` (5) | Иллюстрации, используемые на сайте прототипа | Из папки прототипа `public/images/` |
| `screens/*.jpg` (25) | Скриншоты работающего прототипа: главная (компьютер и телефон), активация стикера, кабинет, путь нашедшего с телефона, уведомление владельцу | Сняты 18.11.2026 с локальной копии прототипа (Next.js), на пустой базе. Все данные на экранах вымышленные: «Тестовый владелец», demo@example.com, «Телеграм @demo_finder». Длинные страницы разрезаны на части `-1`, `-2`… |

Чего здесь нет и почему:

- Базы данных прототипа: в ней учётные записи и контакты — персональные данные. Данных об использовании сервиса нет: прототип не запускался для реальных пользователей.
- Исходного кода прототипа: для стратегии нужны экраны, а не код.
