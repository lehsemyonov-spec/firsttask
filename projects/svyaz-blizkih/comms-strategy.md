## Аудитория и ситуация

Та же, что в продуктовой стратегии: организаторы семейных групп на тарифах с общим пакетом и их участники, давшие согласие на просмотр остатка [F12]. Человек встречает сообщение:
1. **Организатор — в момент, когда у близкого кончается интернет** (рука «сигнал»): он ещё не знает о проблеме [F9].
2. **Участник — при приглашении в группу:** решает, что разрешить видеть [F12].
3. **Участник с низким остатком — только в руке «запрос участника»**, если поток позволит её запустить.
4. **Организатор, уже пользующийся группой** — при расширении после II кв.

## Барьер понимания или выбора

- **Организатор не знает о проблеме вовремя** — опора: он порой узнаёт о перебое из просьбы о помощи [F9]; что главный барьер именно «не знают», а не «не хотят тратить остаток» — гипотеза, проверяется пилотом (доля выделений по сигналу).
- **Участник опасается, что организатор увидит лишнее** — гипотеза; по правилам разрешение на остаток не открывает начисления [F12], это надо сказать прямо.
- **Уведомления воспринимаются как реклама и отключаются** — гипотеза; проверяется долей отключивших уведомления в пилоте.

## Ключевое сообщение

Для организатора: **«У близкого заканчивается интернет — добавьте гигабайты из общего остатка прямо из уведомления».**

Формула: для организаторов семейных групп, у близких которых заканчивается доля интернета, уведомление в приложении — это предупреждение с готовым действием, которое позволяет добавить интернет из общего остатка, не дожидаясь просьбы, потому что оператор видит остаток доли (с согласия близкого), а выделение выполняется по нажатию организатора существующей операцией.

Усиленная версия **«…до того как он останется без связи»** — **снята** (2026-11-22): остаток в приложении обновляется с задержкой 30 мин – 3 ч [F44, F46]. Сигнал приходит с запасом на задержку (D7), но гарантировать «до того как» нельзя. В уведомлении показываем время данных: «У [участник] осталось ≈N МБ (на ЧЧ:ММ)».

Сигнал приходит только когда у группы есть свободный остаток; поэтому обещание «добавьте из общего остатка» выполнимо в каждом показе.

Для участника (при приглашении): **«Организатор будет видеть только остаток вашей доли интернета — не начисления. Разрешение можно отозвать в любой момент»** — формулировка про уведомления организатору — **по воротам I кв.** [U13].

## Подтверждение сообщения

- Выделение из свободного остатка — существующая функция [F9].
- Разрешение на остаток не открывает начисления, согласие отзывается в любой момент — правила оператора [F12].
- После выделения показывается, кому и сколько добавлено (элемент первого запуска).
- Цифры пользы («реже остаются без интернета») — **только после пилота**, из его результата по заранее записанному порогу; до этого цифр нет. Синтетика и прогнозы в сообщениях не используются.

## Роль каналов

| Канал | Задача в пути пользователя | Что показываем |
|---|---|---|
| Уведомление в приложении (организатору, рука «сигнал») | понять и попробовать — в момент проблемы | «У [участник] осталось N МБ. В группе свободно M ГБ. Добавить?» + кнопка |
| Экран приглашения (участнику) | понять и выбрать, что разрешить | кто пригласил; что увидит организатор — только остаток; как отозвать |
| Подсказка участнику (только рука «запрос участника») | попробовать | «Можно попросить у организатора — он получит просьбу с кнопкой» |
| Экран результата | убедиться, что проблема решена | статус «выполняется» → «выделено N ГБ — [участник]», где проверить итог |
| Поддержка | остаться: разобрать спорную операцию | найти выделение по номеру, объяснить статус и что делать дальше |

Продажи и баннер для новых групп **не используются** в плановом году: привлечение новых групп — отдельное решение по O8 или каналу (отказ в продуктовой стратегии). Если оно будет принято, сообщение обязано оговаривать: «на тарифах с общим пакетом, с согласия близкого».

## Проверка обещаний

| Обещание | Чем выполняется в продукте | Статус |
|---|---|---|
| Добавить гигабайты близкому из общего остатка | существующая операция выделения [F9] | есть сейчас |
| Прямо из уведомления (кнопка → операция с подставленным объёмом → подтверждение) | кнопка в уведомлении | будет по плану (II кв., при воротах I кв. на O3) |
| Узнать, что у близкого заканчивается интернет | событие «остаток меньше обычного расхода участника за 3 ч» + уведомление организатору [D7, U15] | будет по плану (II кв., при воротах I кв. на O3) |
| Остаток показан честно | время данных «на ЧЧ:ММ» в уведомлении; задержка 30 мин – 3 ч [F44] | будет по плану (II кв.) || В уведомлении всегда есть из чего добавить | правило «сигнал только при свободном остатке и праве распределять» | будет по плану (II кв.) |
| Организатор видит только остаток, не начисления | раздельные разрешения [F12] | есть сейчас |
| Организатор получает уведомления о низком остатке участника с его согласия | согласие на остаток — если покрывает уведомления; иначе новое согласие | будет по плану, по воротам I кв. [U13] |
| Разрешение можно отозвать в любой момент; после отзыва сигналы прекращаются | отзыв согласия [F12] + прекращение уведомлений | отзыв — есть сейчас; прекращение сигналов — будет по плану (проверка командами кабинета и безопасности до старта) |
| Видно, кому и сколько выделено; повторное нажатие не спишет дважды | экран результата + запрос с ключом идемпотентности | будет по плану (II кв.) |
| Участник может попросить у организатора с готовой кнопкой | рука «запрос участника» | будет по плану, только если поток позволит третью руку (II кв.) |
| Бесплатно, входит в тариф | отдельной платы нет (продуктовая стратегия) | будет по плану (II кв.) |
