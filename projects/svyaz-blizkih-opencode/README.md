# Прогон в другой среде: «Связь для близких и собственных устройств» в OpenCode

Тот же бриф МегаФона и тот же агент (репозиторий версии `031385b`, правила и скрипты не менялись), но **другая среда и другие модели**: OpenCode вместо Claude Code. Прогон сделал участник команды по инструкции для товарища — без подсказок об устройстве агента, отвечая только в точках выбора. Это проверка **переносимости**: работает ли агент вне Claude Code и на других моделях.

Основной демонстрационный проект — [`../svyaz-blizkih/`](../svyaz-blizkih/README.md) (Claude Code). Эта папка — второй, независимый прогон.

## Результат

Все проверки шагов 1–6 (`check --step 6`) проходят без предупреждений. Показатели (`python tools/strategist.py metrics svyaz-blizkih-opencode`): 7 источников; 40 утверждений, из них 18 фактов — все с проверяемым источником, 3 — синтетика модельных интервью (используются только как гипотезы); 12 пробелов; 6 вариантов и 22 возражения; 4 из 4 обещаний подкреплены продуктом; 3 решения.

**Рекомендация совпала по сути с прогоном в Claude Code:** первым — ранний сигнал организатору семейной группы о заканчивающемся интернете близкого, сначала дешёвая проверка (этап 0 / диагностика I квартала), затем пилот.

| | Claude Code (`svyaz-blizkih`) | OpenCode (эта папка) |
|---|---|---|
| Модели | старшая модель Claude | DeepSeek V4.1 Flash, Nemotron 3.5 Super VL (облегчённые, бесплатные) |
| Вариантов / возражений | 10 / 21 | 6 / 22 |

| Оценка вклада в прибыль | 0…0,15 млн руб. в плановом году (осторожно, удержание — гипотеза) | 2,9…7,2 млн руб. в сценариях — заметно оптимистичнее, держится на допущении об оплате (U3) |
| Новые данные | пересчёт, 6 утверждений помечены «устарел», 2 отозваны | новые факты добавлены, решения поставлены на пересмотр; старые прогнозы статусом «устарел» не помечены |
| Язык | без огрехов | единичные огрехи (например, «organisatora») |

Вывод: агент **переносится** — процесс, проверки, точки выбора, перерыв и документ в структуре заказчика сработали в другой среде на других моделях. Глубина и осторожность выводов на облегчённых бесплатных моделях ниже — это ожидаемая цена модели, а не среды.
