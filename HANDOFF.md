# Передача контекста: «Стратег Фабрики продуктов»

Файл для нового чата или Claude Code. Прочитай его целиком, затем `GUIDE.md` (карта репозитория) и `AGENTS.md` (правила агента).

## 1. О чём проект

Конкурсное задание МегаФона «Стратег Фабрики продуктов». Полный текст задания — `docs/task.md`.

Нужно сдать **репозиторий ИИ-агента**: не программу, а папку с инструкциями, знаниями и скриптами. Её открывают в Cursor, Claude Code и других средах. Агент ведёт руководителя цифрового продукта от размытого запроса до:
- проверяемой картины ситуации (что известно, откуда, чего не знаем);
- ≥3 содержательно разных вариантов, **включая «оставить как есть» и «закрыть направление»**, с сильными возражениями;
- согласованных **продуктовой и коммуникационной стратегий** с планом проверки;
- дополнительно: работы после решения (основания, обязательства, пересмотр при новых данных).

**Что сдавать:** репозиторий с инструкцией запуска; демо-проект по брифу МегаФона (бриф опубликуют отдельно; только открытые данные); видео до 10 минут (запрос → работа → варианты → стратегия → продолжение после перерыва); PDF-описание (архитектура, модели и сервисы, промпты, реализованные возможности, время и затраты, ошибки, ограничения).

**Критерии (по 10 баллов):**
- Проработанность — качество самой стратегии.
- Нейротехнологии — агентная система и возможности дополнительного уровня.
- Имплементация — запуск, сквозной путь, продолжение, безопасность, работа на новых задачах.
- Качество — затраты известны, компоненты оправданы, результат понятен.

## 2. Что уже сделано (репозиторий `product-strategist/`)

- **Переносимость:** все правила в `AGENTS.md`; `CLAUDE.md` (`@AGENTS.md`), `GEMINI.md`, `.cursor/rules/`, `.github/copilot-instructions.md` — переходники.
- **Процесс из 6 шагов** (`workflow/01…06`): бриф 🛑 → источники → исследование → варианты 🛑 → стратегии 🛑 → план проверки и решение. У каждого шага есть критерии готовности.
- **Методики** (`knowledge/`): типы утверждений и надёжность, исследование, интервью, варианты, обе стратегии, план проверки, безопасность.
- **Шаблоны проекта** (`templates/`): state, brief, sources, facts (типы: факт / вывод / гипотеза / прогноз / синтетика), unknowns, research-plan, interviews, options (O1 [статус-кво], O2 [закрыть], O3…), product/comms-strategy (с таблицей «Проверка обещаний»), validation-plan, decisions, log, cost, materials/, analysis/.
- **`tools/strategist.py`** (только stdlib) — команды `new`, `list`, `status`, `set`, `check`, `log`, `cost`, `report`, `impact`, `metrics`. `check` проверяет при переходе шага: источники фактов существуют, вывод ссылается на факты, синтетика не служит доказательством (и через цепочки выводов тоже), есть [статус-кво], [закрыть] и вариант изменений, человек сделал выбор, обещания подкреплены продуктом, диапазоны вида «F1–F4» раскрываются.
- **`tools/data_check.py`** — паспорт CSV/XLSX: пропуски, типы, выбросы, проценты > 100, отрицательные суммы, период.
- **`tools/hook.py` + `.claude/settings.json`** — хуки Claude Code: SessionStart (где остановились), PostToolUse (битые ссылки, синтетика, секреты, телефоны и e-mail; код выхода 2). Сами выбирают между `python3` и `python`.
- **Субагенты** `.claude/agents/`: `skeptic` (возражения), `fact-checker` (Sonnet), `respondent` (Haiku) — маршрутизация по стоимости. В других средах выполняются отдельным проходом по тем же файлам.
- **Навыки** `.claude/skills/`: `revise-on-new-data`, `model-interviews`, `data-passport`.
- **`benchmark/`** — методика сравнения с обычным чатом (чек-лист из 12 пунктов, шаблон результатов).
- **`docs/architecture.md`** — черновик PDF; места для цифр помечены ✍️.
- **`tests/`** — 29 автотестов: учебный проект `tests/fixture/` с вымышленными данными, документы для `extract_text` собираются в коде, проверка ссылок в инструкциях. Запуск: `python3 -m unittest discover tests -v`, все проходят.
- **`GUIDE.md`** — карта «что за что отвечает»; `README.md` — инструкция запуска и ключевые решения; `docs/task.md` — полный текст условий.

## 3. Правила доработки (договорённости с владельцем)

- **Сначала опиши, что собираешься менять, и жди согласия**, потом делай.
- Скрипты — только стандартная библиотека Python 3.9+, без внешних зависимостей.
- Всё на русском: тексты, сообщения скриптов, документация.
- После любых правок прогоняй тесты и добавляй новые на исправленное.
- Каждый компонент должен оправдывать свою сложность пользой: так сказано в задании.
- Только открытые данные, никаких закрытых данных компаний; секреты не в репозитории.
