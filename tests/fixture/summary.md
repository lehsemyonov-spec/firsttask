# Резюме для руководителя: Учебный проект

## Рекомендация

Запустить тест фримиума (O3) на 8 недель на части новых пользователей и решить по конверсии в оплату.

## Основания

- Удержание D30 упало с 18,5% до 14,0% за девять месяцев [F1].
- Почти половина негативных отзывов — о цене подписки [F2].
- Связь падения с ценой подтверждается двумя независимыми наблюдениями [F3].

## Риски

- Выручка с подписки снизится раньше, чем вырастет удержание.
- Доход с рекламы неизвестен [U1] — экономика бесплатного уровня может не сойтись.
- Прогноз эффекта неточен [F4] — тест может не показать разницы за 8 недель.

## Что решить сейчас

- Утвердить тест на 10% новых пользователей и порог конверсии 4%.
